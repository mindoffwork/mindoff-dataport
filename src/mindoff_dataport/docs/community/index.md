# Community

Report generation has a way of surfacing friction that isn't obvious until you're actually shipping something: layouts that drift, data shapes that don't fit the contract, edge cases that only appear in production. `mindoff-dataport` improves from that kind of real-world feedback. This section is the practical guide for contributing code, reporting issues, asking questions, and collaborating with other developers building on the library.

Before contributing, please read through the [Developer Guide](../developer_guide/index.md) and [Architecture](../architecture/index.md) so you have enough context to help effectively.
