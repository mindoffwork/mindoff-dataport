# Developer Guide

Turn an Excel workbook you already designed into a reusable report template and export to `.xlsx` and `.pdf` from the same source. This Developer Guide is the practical handbook for building real reports with `mindoff-dataport`. It focuses on getting work done: extracting templates, binding data, and exporting clean output. If you want to understand how the machinery fits together under the hood, head over to [Architecture](../architecture/index.md).

If you are new, read top to bottom; each page builds on the one before it. If you are looking for a specific feature, jump straight to it from the menu below.
